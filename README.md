# ASP Portal for Windows

[Download ASP Portal Setup](https://github.com/Prabhat-godrej/asp-portal-downloads/releases/latest/download/ASP-Portal-Setup.exe)

1. Download and run **ASP-Portal-Setup.exe**.
2. Open **ASP Portal**.
3. Sign in with your approved Salesforce ASP login.

Only login IDs approved by the ASP Portal administrator can use the application. A GitHub account is not required to download the installer.

Future versions are announced inside the app. Installing a newer version preserves this device’s saved app data.

This repository contains installers, checksums and update information only. Application source and administrator credentials remain private.
